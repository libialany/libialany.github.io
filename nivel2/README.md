## Descripción

En este nivel se aprenderá a configurar y administrar los principales servicios que ofrece TrueNAS para compartir información y proteger los datos de una organización. Los participantes implementarán protocolos de acceso a archivos, configurarán mecanismos de protección mediante instantáneas y replicación, y desplegarán aplicaciones utilizando contenedores.
